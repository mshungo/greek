# Naralingo Graeca（古典ギリシア語・ひとり用）

フランス語版 Naralingo の姉妹版。ログインは `MORITA7k3q` / `shika`（ID の大文字・小文字は区別しない）。

## ファイル
| ファイル | 中身 |
|---|---|
| `index.html` | 入口（1ページで全画面を切りかえる：#/ ホーム、#/day/N レッスン、#/review 復習、#/tables 文法表） |
| `app.js` | しくみ（ログイン・記録・復習カード・ギリシア文字入力・問題の実行・画面） |
| `course.js` | 教材データ（第1週＝White, *The First Greek Book* Lesson I–VI） |
| `reading.js` | 読み（ローマ字転写と IPA＝復元アッティカ発音）。α ι υ の長さは語ごとにここで登録する |
| `style.css` | 見た目（フランス語版の base.css と同じ色・形。アクセント色だけ青） |
| `config.js` | 同期用 Apps Script の URL（空なら端末内だけに記録） |
| `apps-script/Code.gs` | 同期用サーバー（任意）。手順はファイル冒頭 |

`The First Greek Book.pdf` を同じフォルダに置いておくと、各レッスンの「原典 p.N」から該当ページが開く。

## 1日の流れ
1. 復習カード（間隔反復：翌日 → 3日後 → 1週間後 → 2週間後 → 1か月後 → 定着）
2. レッスン：解説 → 単語（ミニテスト後にカード化）→ 練習（10問、まちがいは3問後に再出題。終えると変化形がカード化）→ 読解（語タップで語釈。終えると文がカード化）→ テスト（8割で合格）

## 教材を足すとき（第2週以降）
`course.js` の最後に `DAY({...})` と問題（`C` / `W` / `B`）、変化表（`N` / `A` / `V`）、語釈（`X`）を足す。
問題IDは「日-通し番号」なので、既存の日の問題は**最後に**足す（途中に挟むと記録がずれる）。
読解の文の語はすべて語釈辞書（変化表から自動生成＋`X`）に載っている必要がある。

## 入力
ローマ字（ベータコード風）→ ギリシア文字：`a b g d e z h q i k l m n c o p r s t u f x y w`、記号は母音のあとに `) ( / \ = j`（j＝ι下書き）。
アクセント・気息は省略しても正解（設定で厳密にできる）。ι下書きは与格の印なので省くと不正解。
